# Conversion Calculator Plus — website

Marketing page and privacy policy for the iOS app
[Conversion Calculator Plus](https://apps.apple.com/us/app/id1113920724).

Served by GitHub Pages from this repository's root:

- `index.html` — marketing page, with a `#support` section (the App Store
  Marketing URL and Support URL both point here)
- `privacy.html` — privacy policy (the App Store Privacy Policy URL)

Plain static HTML, no build step and no external assets. Edit the files and
push; Pages redeploys on its own.

`.nojekyll` stops Pages running the files through Jekyll.
