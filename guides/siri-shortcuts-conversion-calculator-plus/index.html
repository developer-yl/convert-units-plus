How to use Siri and Shortcuts with Conversion Calculator Plus

Set up Siri, convert units by voice, run saved converters, update widgets and build an Apple shortcut with Conversion Calculator Plus.

By Adysseus, publisher of Conversion Calculator Plus

Use Siri with Conversion Calculator Plus to convert units, run a saved converter or change the amount shown by a saved converter’s widgets. You can also use the same actions in Apple’s Shortcuts app. The English spoken app name in the examples is Convert Plus.

Before you start: Siri conversions and interactive widgets require an active Premium subscription. The examples below use English; speech recognition and available phrases depend on Siri’s language. Translated commands need their own device checks.

Set up the app and Siri

  1. Install or update Conversion Calculator Plus, then open it once so its actions and saved converters can become available to Siri.
  2. Check your Premium access in the app. If you already subscribed but access is missing, use Restore Purchases and reopen the app.
  3. In your device’s Settings, find Siri or Apple Intelligence & Siri. Enable voice activation, or use your device’s Siri button shortcut. Menu names vary with iOS.
  4. For these English examples, choose an English Siri language. In the app, open Settings → Siri → Using Siri for its illustrated conversation tutorial.

You can begin with a one-off conversion. A saved converter or Home Screen widget is not needed for that route.

Convert units without saving a converter

Say “Hey Siri, convert with Convert Plus.” Answer the prompts in this order:

  1. Amount: “10.”
  2. Category: “Length.”
  3. From unit: “Meters.”
  4. To unit: “Feet.”

Siri returns the conversion result. Prompt wording and number formatting may differ from this example. The category helps distinguish names that occur in different kinds of measurement. Use complete names such as “square meter” or “meter per second” when appropriate.

To start another conversion, say “Hey Siri, convert another with Convert Plus.” This starts a new action; it does not automatically carry over the previous category and units.

Save a converter for a conversion you repeat

A short, distinctive name lets you request the unit pair without speaking both units each time.

  1. Open Widgets in the app; it is also available through Settings.
  2. Tap Create converter.
  3. Enter Meters to Feet as the name.
  4. Choose Length, with Meter as the source and Feet as the destination.
  5. Set a starting amount and tap Save converter.

Say “Hey Siri, run Meters to Feet in Convert Plus.” Siri asks for the amount to convert. Replace “Meters to Feet” with your saved name if you chose something else.

You can instead say “Hey Siri, run a saved conversion in Convert Plus.” and choose the converter when asked. Running a saved conversion calculates the amount you supply; it does not change the saved widget amount. Saving the converter is enough for this Siri action—you do not have to place a widget on the Home Screen.

Try a one-off conversion, then save the pair you use most often. Siri actions require Premium.

Change a Home Screen widget’s amount by voice

To see the result on your Home Screen, add a Conversion+ widget. Touch and hold the placed widget, choose Edit Widget and select the saved converter you created.

Say “Hey Siri, use Convert Plus to update Meters to Feet.” When Siri asks for the new amount, say “25.” This action updates the saved amount and requests a widget refresh. Every widget using that saved converter receives the change; the time it appears is managed by iOS.

Siri identifies the converter by its saved name, not its Home Screen position. Use separate saved converters, such as “Travel Length” and “Work Length,” when voice updates should affect different groups of widgets.

Build a shortcut using the app’s actions

In Apple’s Shortcuts app, find Conversion Calculator Plus under App Shortcuts. Its tiles include Convert Units, Convert Saved and Set Widget Amount. The saved-conversion action’s fuller editor title is Convert with Saved Converter.

  1. Create a new shortcut with the + button and name it My Length Check.
  2. Open the action picker and search for Convert with Saved Converter. Select the action belonging to Conversion Calculator Plus.
  3. Choose Meters to Feet for Saved Converter and enter 10 for Amount.
  4. Add Apple’s Show Result action and use the conversion action’s returned value as its input.
  5. Run the shortcut in the editor and check the displayed result, then finish saving it.

Activate Siri and say “My Length Check.” This runs your custom shortcut with its configured amount. Edit Amount to change it. Apple documents creating shortcuts and running them by name with Siri; control labels vary between iOS versions.

If Siri cannot find the action or stays silent

  • Action missing: update and open the app, then look in Shortcuts for the app’s actions. Try running the action there to separate setup problems from voice recognition.
  • Wrong saved converter: check the exact saved name and avoid duplicate names. Use the generic saved-conversion command to choose one.
  • Units misunderstood: use a named saved converter to avoid repeating ambiguous unit names.
  • No spoken reply: in Siri settings, find Responses or Siri Responses and select the spoken-response option, such as Prefer Spoken Responses. iOS controls speech output.
